# User Guide (step by step)

## One-time setup (Host)
1. Open the dashboard and use **Share** to invite teammates by email (eligible Claude plan required).
2. Ask everyone to open the link. First-time visitors appear as *Pending approval* (read-only).
3. In **Team, Access & Workload**, choose a role, link each person to a name on the roster, and click **Approve**.

## Running a campaign
1. **Template Library** – choose a category, set Launch Day (T-0) and campaign name, click *Preview schedule*, then *Generate selected tasks*.
2. **Task Schedule** – review tasks in List or Board view; filter by status, category or owner; update status on each card.
3. **Monthly Calendar** – click a day number to add a post, task or event; drag items to move them; pick a project for colour coding.
4. **AI helpers (optional)** – *AI Campaign Planner* drafts posts and production tasks for a date range; *AI Persona Fit* checks which persona an idea targets.
5. **Daily check** – open **Alerts & Timeline Check**; use *Generate LINE summary* to copy a status message for the team chat.
6. **On-site day** – use **On-site Shoot Checklist**; tick, add or delete items; restore defaults if needed.
7. **After publishing** – enter reach/engagement numbers from Meta Business Suite and TikTok Analytics in **Performance & AI Insights**, then run the analysis.
8. **Share results** – export the monthly calendar as PNG, CSV or PDF.

## Roles
| Role | Can do |
|---|---|
| Host | Everything, including members and projects |
| Editor | Edit everything except members and projects |
| Assignee | Update status, completion and metrics of items assigned to them |
| Viewer | Read-only, can export |

## Notes
- Changes save automatically; if two people edit the same part at the same moment, the later save wins.
- Browser alerts only fire while the page is open; automatic LINE/email alerts are not available.
- The dashboard cannot pull data from Facebook or TikTok automatically; enter or paste numbers manually.
